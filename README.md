I'm a software developer with a foundation in the **Microsoft .NET ecosystem** and hands-on experience building web applications across the stack.

I work across backend development, database design, API development, and frontend implementation. My approach is to understand the problem behind a feature, design a maintainable solution, and pay attention to the details that make software reliable in day-to-day use.
